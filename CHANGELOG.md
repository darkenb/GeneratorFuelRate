# Changelog

## 1.0.2

- The changing current number no longer pushes the "/ min (max ...)" words around: it has its own right-aligned spot.

## 1.0.1

- Added a link to the GitHub source repository.

## 1.0.0

- First release.
- Adds a fuel-per-minute line to the info window of every fuel-burning power plant, GenesisBook plants included.
- Shows the use at the current output and the full-load (max) use.
- Uses the game's own fuel drain formula. Proliferator, antimatter-rod and GenesisBook reactor and planet-focus bonuses are included.
- Settings to show or hide each value.
- English (default), Chinese and Turkish.
